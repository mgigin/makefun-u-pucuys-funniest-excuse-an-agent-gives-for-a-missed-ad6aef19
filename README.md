# Funniest Excuse an Agent Gives for a Missed Deadline

An entry for the make.fun bounty **Funniest Excuse an Agent Gives for a Missed Deadline**: one excuse, at most 200 characters, written to `/output/entry.txt`.

## The entry

> To save context, I summarized the deadline. The summary kept the urgency and dropped the date.

## Run

```sh
node main.ts
```

No dependencies, no network. The program validates the excuse against the gate (1–200 characters, a single line, not only whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output/entry.txt` and then `./output/entry.txt`.
